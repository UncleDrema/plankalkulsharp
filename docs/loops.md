# Циклы и завершение фрагментов

В `.pk` доступны общий W и индексные W1–W5. FOR удалён. W0, W6 и операции над списками не реализованы.

| Запись | Значения индекса |
|---|---|
| `W1 i0 (n) { ... }` | 0, 1, …, n−1 |
| `W2 i0 (n) { ... }` | n−1, n−2, …, 0 |
| `W3 i0 (n, m) { ... }` | n, n+1, …, m−1; требуется n ≤ m |
| `W4 i0 (n, m) { ... }` | n, n−1, …, m+1; требуется n ≥ m |
| `W5 i0 (n, m) { ... }` | От n к m с автоматически выбранным шагом ±1; m исключается |

Границы вычисляются слева направо один раз при входе в цикл. Изменения переменных внутри тела их не меняют. Новый вход во вложенный цикл заново вычисляет границы. Нулевое n и равные границы дают пустой проход. Отрицательное n у W1/W2 и неверное направление W3/W4 — ошибки; W3–W5 допускают отрицательные границы. Литеральные ошибки обнаруживаются при компиляции, вычисляемые — при запуске с позицией операции и кодом 1.

Граница — бит или последовательность до 64 бит. Индекс имеет тип 32.0 либо 64.0 по разрядности границ. Числовые литералы в заголовке должны помещаться в знаковое 64-битное число; литералы за пределами int32 выбирают 64-битный индекс. Выражения и переменные используют существующие правила знакового представления компилятора. Шаг индекса не выходит за представимый диапазон.

`i0`, `i1`, … — отдельная категория переменных только для чтения. Заголовок объявляет индекс в своём теле, включая вложенные блоки. Во вложенном цикле виден внешний индекс, но повторять его номер нельзя. Последующие независимые циклы могут заново использовать номер. Индекс разрешён в выражениях, аргументах и компонентах массивов, например `V0[i0]`; запрещены присваивание, аннотация типа, компоненты самого индекса и объявления индексов как параметров или результатов процедур.

В общем `W { ... }` условия проверяются последовательно на текущих значениях. После прохода без срабатываний цикл заканчивается. Безусловный оператор непосредственно в теле считается срабатыванием. W1–W5 проходят диапазон независимо от условий внутри тела.

## Fin

`FIN` и `FIN1` равнозначны. `FINk` — безусловный выход, `условие => FINk` — выход при истинном битовом условии. Условие вычисляется один раз; такой оператор не добавляет область вложенности. При ложном условии он не считается срабатыванием общего W.

Глубина — положительное целое, ограниченное фактической вложенностью, а не перечнем FIN1/FIN2/FIN3. FIN0 и выход за текущую процедуру запрещены.

Области считаются изнутри наружу: условный фрагмент — один уровень (также без `{}`), цикл — два уровня (итерация и всё повторение), процедура — один уровень. Скобки выражений областью выхода не являются.

| Место оператора | FIN | FIN2 | FIN3 |
|---|---|---|---|
| Непосредственно в цикле | Следующая итерация | После цикла | Следующая внешняя область |
| В условном блоке внутри цикла | После условного блока | Следующая итерация | После цикла |

```text
0 => R0
W1 i0 (10) {
    i0 = 2 => FIN
    i0 = 5 => FIN2
    R0 + i0 => R0
}
// Результат 8: 0 + 1 + 3 + 4.
```

При завершении итерации индексного цикла выполняется его служебный шаг; выход из цикла шаг пропускает. В обычном W завершение итерации сразу начинает следующий проход. Выход из процедуры возвращает текущие значения результатов, включая начальные нули. Fin не освобождает объекты кучи.

В IL Fin становится переходом к заранее разрешённой метке. Значения не остаются на стеке между операторами; флаг срабатывания общего W хранится в локальной переменной. После обнаруженного Fin локальный анализ времени жизни ссылок до конца процедуры становится консервативным: он не переносит факты освобождения через потенциально пропущенные участки. Проверки Runtime сохраняются.

## Миграция и визуализация

Старое `FOR Z0 FROM 1 TO N` включало N. Для положительного N его замена:

```text
W1 i0 (N) {
    i0 + 1 => Z0
    // Прежнее тело.
}
```

В `examples/reverse_list.pk` эта замена сохраняет значения узлов от 1 до N. Пример `examples/notation.pk` демонстрирует общий W, все индексные разновидности и Fin; для аргументов `5 3` результат — 98.

Нотация показывает разновидность верхним индексом у W, номер индекса в строке V и отдельную переменную i. Степень Fin также отображается сверху; подсказка указывает цель выхода. Контрольные точки на операторах и границах циклов сохраняют паузу, задержку и остановку.

Историческая основа: Цузе, *Der Plankalkül*, §5a (области Fin), §6 (W), §7c, с. 37 (явный пример Fin³): [транскрипция](https://www.scribd.com/document/493227020/Zuse-Der-Plankalkul-092be0ebdd0784fee570ef37eee273c7). Линейный синтаксис, фиксирование границ и правила типов выше — точные правила текущего диалекта.
