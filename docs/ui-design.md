# Интерфейс рабочей среды

Назначение — открывать `.pk`, сопоставлять текст с нотацией, читать стандартные планы и наблюдать за исполнением. Исходник только для чтения; редактор и новая модель проектов не добавлены.

Пользователь согласовал постоянную левую навигацию, код и нотацию рядом, результаты снизу и скрываемую память справа. Справка и каталог занимают центральную область того же окна. История запусков и снимки исходника сохраняют прежнюю семантику.

Визуальная система реализована в `Theme.xaml`: Segoe UI 13 для интерфейса, Consolas для исходников и дампов; фон рабочей области `#F3F5F6`, белые поверхности, основной текст `#22343D`, вторичный `#52636D`, границы `#D5DDE2`, акцент `#176679`. Акцент используется для запуска и интерактивных состояний. Стандартные WPF-таблицы, меню, вкладки и полосы прокрутки сохраняют привычное поведение. Разделители регулируют плотность содержимого, память можно убрать для чтения на узком экране.

Каталог расширяется данными Python-пакета. Описания и примеры находятся рядом с сигнатурами в `stdlib/catalog.json`, а не в перечне имён внутри WPF. Неподставленный шаблон не получает выдуманную нотацию: интерфейс поясняет необходимость конкретных типов.

Проверка без показа окна покрывает загрузку XAML, существующую подсветку, переключение справки, поиск, каталог без специализаций и скрытие памяти. Проверка реального вида, размеров при масштабировании Windows и удобства работы передана пользователю; она не заменяется успешной сборкой.
