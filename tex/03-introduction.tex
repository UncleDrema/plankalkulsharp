\chapter*{ВВЕДЕНИЕ}
\addcontentsline{toc}{chapter}{ВВЕДЕНИЕ}
Графовые базы данных используют узлы и связи для представления данных в виде графов и относятся к классу NoSQL систем.
Графовые модели имеют широкое распространение в задачах обработки знаний, социальных и биологических процессов и финансовых потоков~\cite{graphs_bio}.

NoSQL базы данных разнородны и предоставляют различный интерфейс для работы, поскольку могут основываться на разных подходах к хранению и обработке данных.
Как показывают исследованяи, они предоставляют большую эффективность в задачах аналитики данных и масштабирования~\cite{sql_or_nosql_perf}.

Язык SQL является самым распространенным средством для работы с базами данных.
Вследствие этого, наличие возможности работы с базой данных при помощи SQL упрощает разработку и позволяет не адаптировать прикладное ПО к работе с данными при помощи нового набора инструкций~\cite{sql_or_nosql}.

Трансляция SQL выражений в инструкции работы с NoSQL базами данных применяется для обеспечения работы устаревших информационных систем с современными нереляционными базами данных \cite{sql_to_nosql}.
Альтернативным применением данного механизма является поддержка возможности использовать известные разработчикам инструкции на языке SQL для работы с NoSQL базами данных.

Цель работы -- разработать программное обеспечение, реализующее метод кодогенерации инструкций для работы с графовой базой данных.

Для достижения поставленной цели необходимо решить следующие задачи:
\begin{enumerate}
	\item Провести анализ существующих подходов к кодогенерации и особенностей предметной области;
	\item Спроектировать библиотеку кодогенерации инструкций для работы с графовой базой данных;
	\item Разработать библиотеку кодогенерации и интерфейс командной строки к ней;
	\item Исследовать корректность генерации инструкций работы с графовой базой данных из SQL выражений.
\end{enumerate}
